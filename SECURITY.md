# Security Policy

## Supported Versions

We supply security updates to the latest minor version release of Zion Edge Gateway. 

| Version | Supported |
| ------- | --------- |
| 0.1.7   | Yes       |
| < 0.1.7 | No        |

## Reporting a Vulnerability

If you discover a potential vulnerability within Zion Edge Gateway, please do not disclose it publicly.

Instead, please use [GitHub Security Advisories](https://github.com/fabriziosalmi/zion/security/advisories) to report the vulnerability privately via the "Report a vulnerability" button.

### What to Include
When reporting, please provide:
- A description of the vulnerability.
- Steps to reproduce the issue (including `zion.toml` configurations if applicable).
- A Proof of Concept (PoC) if available.
- Potential impact.

### What Happens Next
1. The report will be acknowledged within 48 hours.
2. We will investigate the issue.
3. If valid, we will develop a patch.
4. We will coordinate a timeline with you for releasing the patch and publishing the advisory.
